# 06. Quality checklist (run at the end of each prompt and fully at the end)

## Visual (screenshots 375x812, 768x1024, 1440x900, 1920x1080)
- [ ] Hero fits the first viewport: H1 max 2 lines, CTA visible without scrolling, GLAMOOD giant partly behind Fabio, not cropped awkwardly on mobile.
- [ ] Hero photo and cartoon perfectly overlap (toggle both at 50% opacity to check).
- [ ] No section repeats the same layout family; no three equal cards in a row; bento has exactly 4 cells.
- [ ] White and petrol dominate; wood and brass only as accents; no red on petrol.
- [ ] Decorations never cover text or buttons; they stay behind or at edges.
- [ ] Stickers and mascots are clean (no halos, no speckles).
- [ ] Footer sign-off readable and full width.

## Interaction
- [ ] Loader shows once per session, is skippable, does not delay LCP.
- [ ] Header hides/shows correctly; active nav item follows the section.
- [ ] Menu: opens/closes, focus trap, Esc, scroll lock, waves animate and stop when closed.
- [ ] Shelf: click, arrows, drag, keyboard all work; detail sheet opens/closes with Esc and browser back.
- [ ] WhatsApp links include the prefilled text; "Portami da Glamood" opens the right maps app.
- [ ] Easter eggs open by tap/click and by keyboard path; they close with Esc.

## Accessibility
- [ ] Lighthouse accessibility >= 95; all images have Italian alt text; decorative images `alt=""`.
- [ ] Visible focus on every control; tab order logical; menu and modals labelled.
- [ ] Reduced motion: page complete and usable with no motion.

## Performance
- [ ] Lighthouse mobile performance >= 90; LCP < 2.5 s; CLS < 0.1; total JS < 180 KB gzip (excluding lazy chunks).
- [ ] No PNG master shipped; all images responsive with width/height.
- [ ] WebGL/canvas loops pause off-screen.

## Content
- [ ] No invented data; every TODO listed in TODO.md; no em/en dashes in visible text; Italian spelling checked (accents: più, è, perché).
